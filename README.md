# KeyFlip

KeyFlip یک ابزار سبک برای ویندوز است که متن انتخاب‌شده را بین چیدمان صفحه‌کلید فارسی و انگلیسی تبدیل می‌کند.

برای مثال، اگر متن را با زبان کیبورد اشتباه تایپ کرده باشی، آن را انتخاب کن و میانبر KeyFlip را بزن تا متن به چیدمان درست تبدیل شود.

## قابلیت‌ها

- تبدیل دوطرفهٔ متن فارسی و انگلیسی
- تشخیص خودکار زبان متن انتخاب‌شده
- میانبر قابل تغییر (پیش‌فرض: `Ctrl + Shift + M`)
- رابط تنظیمات گرافیکی
- اجرا در System Tray
- امکان اجرا هنگام روشن‌شدن ویندوز
- پشتیبانی از ساخت فایل اجرایی با PyInstaller

## پیش‌نیازها

- Windows
- Python 3.10 یا جدیدتر

## نصب و اجرا

ابتدا پروژه را دانلود یا Clone کنید، سپس در پوشهٔ پروژه این دستورها را اجرا کنید:

```bash
pip install -r requirements.txt
python main.py
```

پس از اجرا، برنامه در System Tray فعال می‌شود.

## نحوهٔ استفاده

1. متنی را که با زبان کیبورد اشتباه نوشته‌اید انتخاب کنید.
2. کلیدهای `Ctrl + Shift + M` را فشار دهید.
3. KeyFlip متن انتخاب‌شده را به چیدمان فارسی یا انگلیسی تبدیل می‌کند.

می‌توانید میانبر و تنظیم اجرای خودکار را از پنجرهٔ Settings تغییر دهید.

## ساخت فایل اجرایی

برای ساخت نسخهٔ اجرایی ویندوز:

```bash
pyinstaller KeyFlip.spec
```

فایل اجرایی ساخته‌شده در پوشهٔ `dist` قرار می‌گیرد.
